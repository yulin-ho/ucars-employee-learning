安装与使用

在 Codex 中使用

安装

  • 下载并解压完整压缩包，保留 ucars-employee-avatar 文件夹及内部结构。
  • 将整个文件夹放入自己当前 Codex 用户可用的 Skills 目录；如果不清楚目录位置，可让 Codex 帮你定位并安装。
  • 按当前 Codex 提示刷新或重启，再确认能识别“UCARS 员工头像” Skill。

生成头像

  • 说明要生成头像，并提供员工本人照片。
  • 先确认照片本人同意将照片用于 Codex 图像生成。
  • 每位员工单独生成；生成后核对本人辨识度、服装细节和 Logo。
兼容范围：此版本按 Codex Skill 结构制作。其他 AI 工具能否直接使用，取决于它是否支持相同 Skill 格式和图片参考方式，目前未逐一验证。

卡兹克开源项目

这组项目统一收录在 khazix-skills 主仓库，下面链接直接进入各项目目录。

hv-analysis｜横纵分析法

围绕一个研究对象，梳理发展变化并对照同期竞品。适合较深入的产品、公司或行业研究；简单事实查询不必使用。

khazix-writer｜写作风格参考

将作者个人公众号写作方法整理为规则，适合了解其表达习惯。使用时应明确这是特定作者风格，不等同于 UCARS 品牌文风。

aihot｜AI 资讯查询

按日期、主题或关键词查询 AI 行业动态。使用前查看其数据来源、当前可用范围和联网方式。

storage-analyzer｜存储空间分析

分析设备存储占用并生成报告。涉及文件清理时，先核对路径与影响；删除操作由本人确认，不要仅凭自动建议执行。

neat-freak｜项目资料整理

帮助对照项目当前状态整理说明文档和记忆内容。修改前先确认目标文件，并检查差异，避免覆盖有效信息。

其他作者与官方项目

文章还介绍了以下开源项目。功能和兼容性以各自 GitHub 仓库当前说明为准。

Superpowers｜结构化工作流程

一组帮助 Agent 先澄清需求、拆解任务并逐步执行的工作方法。适合希望让复杂开发任务更有步骤的人；不同 Agent 的支持方式需查看仓库说明。

docx｜Word 文档处理

Anthropic 开源 Skills 中的 Word 文档处理说明与流程参考。适合经常需要创建或编辑 Word 文件的场景。

xlsx｜Excel 表格处理

Anthropic 开源 Skills 中的 Excel 工作簿处理说明与流程参考。处理业务数据时仍需核对公式、口径和结果。

pdf｜PDF 处理

Anthropic 开源 Skills 中的 PDF 阅读、生成和检查流程参考。适合需要关注页面排版或文档质量的任务。

pptx｜演示文稿处理

Anthropic 开源 Skills 中的演示文稿制作与编辑流程参考。生成后需要检查页面内容、版式和字体显示。

Web Access｜网页访问

通过本地浏览器访问网页的开源项目。可能涉及浏览器登录状态和网页数据，安装前应确认权限、数据处理方式及公司工具要求。

PUA｜任务推进辅助

为 Agent 提供任务卡住时的检查和换思路提示。把它作为辅助流程参考，结果仍需按任务标准检查。

claude-mem｜会话记忆

面向 Claude Code 的会话信息记录与检索项目。关注本地保存了什么信息、保存位置及清理方式，并确认与当前工具兼容。

Skill Creator｜创建 Skill

Anthropic 开源的 Skill 创建指南与工具。适合把经验证的重复工作整理成可复用说明；生成后仍需本人审核与测试。

安装前检查：打开 GitHub 仓库，先读 README、许可和安装说明；确认来源可信、权限与任务匹配，并遵守公司数据和工具规范。不要把未知仓库地址直接交给 Agent 后就默认安装或运行。外部项目的版本、兼容范围和安全性可能变化，本页面不自动同步上游更新。
